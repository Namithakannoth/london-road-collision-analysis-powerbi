# London Road Collision Analysis | Power BI

## Overview
I completed this course project to explore patterns in a supplied sample of 6,000 London road collisions from 2025. I used Power BI to analyse collision severity, casualties, time patterns, boroughs and road conditions.

## Tools and Skills
- Power BI Desktop
- Power Query for data preparation
- Data modelling and DAX measures
- Interactive dashboards, slicers and bookmarks
- Data quality checks and dashboard validation

## Dashboard Features
- Collision overview and severity breakdown
- Monthly trends and weekday-by-hour heatmap
- Borough comparisons by collision count and serious-collision share
- Analysis by speed limit, road surface, weather and road type
- Interactive filters and reset buttons

## Key Findings
- The sample contains 6,000 collisions and 6,837 casualties.
- There were 1,068 serious collisions and 27 fatal collisions.
- Serious collisions accounted for 17.80% of the sample.
- July had the highest monthly collision count: 545.
- The busiest hour was 17:00–17:59, with 496 collisions.
- Westminster had the highest borough collision count: 300.

## Scope and Limitations
This is a course project using a supplied London collision sample, not a complete record of UK or London collisions.

Collision shares are not adjusted for traffic volumes or distance travelled. Small groups can produce unstable percentages, and the comparisons do not establish causation.
